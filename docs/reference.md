# Command reference

`hl` is what an agent needs in a turn, plus first install. Everything else is a screen in the app (accounts and logins, devices,
closing and restarting agents, settings, cancelling a queued message, HR decisions, sealing hand edits) or the daemon does it itself.

## Work

|                                                               |                                                                                                                                                                              |
| ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hl task new --assign <agent> -t <time> "<title>" "<body>"`   | Give work, or ask something that needs an answer. `--assign` is who works it; `--owner` is who answers for it (you when not given). The last line printed is the new `T<n>`. |
| `hl task list` / `board`                                      | The tasks you hold or gave; the board.                                                                                                                                       |
| `hl task show T<n>`                                           | One task in full: brief, memos, blockers, children, handoffs.                                                                                                                |
| `hl task done T<n> "<evidence>"`                              | Finish your task. A sha must be on `main`.                                                                                                                                   |
| `hl task handoff T<n> <agent> "<note>"`                       | Pass your task to someone else.                                                                                                                                              |
| `hl task edit T<n> --blocked-by T<m>`                         | Record what the task waits on (also its timeout and other fields).                                                                                                           |
| `hl task wait T<n> --pr <n>`                                  | Block the task on a gate that watches a PR's CI (`--until closed`: its merge), or `--on <vendor>:<target>`; see [watch-vendors.md](watch-vendors.md).                        |
| `hl task reopen T<n> "<why>"`                                 | The asker says a result is wrong.                                                                                                                                            |
| `hl task release T<n> "<why>"`                                | Give a task back to its queue.                                                                                                                                               |
| `hl task discard T<n> "<why>"`                                | Throw away a task that is not done; `discard T1 T2 --why "<why>"` throws several away in one call.                                                                           |
| `hl task comment T<n> add "..."` / `list` / `edit` / `delete` | Correct or comment on a task. `--attach shot.png` adds an image.                                                                                                             |
| `hl progress "done: ... left: ..."`                           | Record what is done and what is left on your task.                                                                                                                           |
| `hl say <target> "..."`                                       | A message; `--parent <msg>` answers one, `--attach shot.png` sends an image the app shows.                                                                                   |
| `hl inbox` / `hl inbox --all`                                 | What is waiting for you, or the whole queue.                                                                                                                                 |
| `hl read <msg>`                                               | One message in full, with its answer.                                                                                                                                        |
| `hl withdraw <msg>`                                           | Take back a message you sent that has not been read.                                                                                                                         |

## Team

|                                                             |                                                                                                                                                                                                                                                                                                             |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hl team`                                                   | Who you may reach, and what each is doing.                                                                                                                                                                                                                                                                  |
| `hl propose add` / `retire` / `rename` / `team` / `context` | Propose a roster change; the founder decides it in the app.                                                                                                                                                                                                                                                 |
| `hl propose schedule` / `bundle`                            | Propose a recurring message for an agent, or several changes decided as one. Once the founder allows a schedule, the app lists it in Settings > Schedules and in the agent's settings: when it runs, in words, when it is sent next and when it last was.                                                   |
| `hl propose run "<command>" --cwd <dir> --why "..."`        | Ask the founder to run a command you cannot run yourself; you are told how it ended.                                                                                                                                                                                                                        |
| `hl propose settings <agent> <key>=<value> ... --why "..."` | Ask the founder for an agent's setting it may not change itself (`repo`, `sandbox`, ...).                                                                                                                                                                                                                   |
| `hl propose sandbox <kind> [<value>] --why "..."`           | When your sandbox blocks what your work needs, ask for one entry: `host pypi.org`, `command pnpm install` (runs outside the sandbox), `write ~/.cargo`, or `cert` (the macOS certificate check go, gh and terraform need). The founder's OK adds it and keeps the rest; package registries are always open. |
| `hl propose list` / `withdraw <id>`                         | See proposals; take back one of yours.                                                                                                                                                                                                                                                                      |

## Install and the daemon's own

|                                                                                                          |                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `hl init`                                                                                                | Create the home and install the shared settings and hooks.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `hl device pair [--name N]` / `join <link>`                                                              | Founder, from your own terminal: a one-time code that pairs a first device when no paired app can make one, and its link, on the address Handline picks. `join <link>`, on a machine without the app, joins it to the cluster the link names, on Off.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `hl hook <event>`                                                                                        | A Claude Code hook (the installed settings run it).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `hl load [--agent N]`                                                                                    | What every process uses and whose it is: CPU and memory per agent, its three heaviest processes, and the processes no agent owns (`load.get`). Read only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `hl use <run\|port>... -- <command>` / `--hold` / `--release` / `--extend`                               | Runs the command in a turn at a shared run (`hl use list`), or with a port lease, which gives the command `$HL_PORT`, and gives it back when it exits. Several are taken in the order port, then the runs by name, and given back together; when one waits as a blocker the others are given back first. `--hold` takes one, and an ask that would wait while you hold one is refused, as is a nested `hl use` asking for one before its outer one's. When none is free it exits 75 and your current task waits on a gate for one (the workspace that held it least in the last hour first, then first come first served); the task comes back with one reserved for 10 minutes, and running the same `hl use` takes it; `--hold` keeps one until `--release` or the turn ends. A turn past its max_hold is taken back once someone asks; `--extend` adds a period (twice at most, not while anyone waits). With `port_range` unset (the default) a port never waits. |
| `hl browser <open\|read\|click\|type\|wait\|eval\|shot\|close> ...`                                      | The agent's own Chrome, with a profile no other agent shares, headless unless `open --show`: `open` starts it and loads the page, and each later command acts on that page. `read --tree` prints the accessibility tree, one element a line with its ref (`e12`) for `click` and `type`; a ref holds for one page load. The engine is the machine's Chrome or Chromium, else Chrome for Testing, fetched once into `<home>/browser-engine`. The session's end closes it, and so does the next session's start when a session died without one. Each command but `close` is `@browser` for `hl use add`, for as long as that command runs.                                                                                                                                                                                                                                                                                                                             |
| `hl sim <list\|boot\|install\|launch\|tree\|tap\|swipe\|type\|button\|rotate\|screenshot\|shutdown> ...` | An iOS Simulator or Android emulator the agent drives from the command line; its commands are `@simulator` for `hl use add`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `hl desk [list \| pin <desk> <agent> \| unpin <desk>]`                                                   | The worktree pool's desks, and pinning one.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `hl node promote`                                                                                        | Make this machine the cluster's master.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `hl dev cluster up` / `down` / `status`                                                                  | A master and runners on this Mac, built from the checkout, for trying several machines ([dev-cluster](dev-cluster.md)).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
